# RFC 9309 — 크롤러는 자기 이름의 그룹을 찾으면 `User-agent: *` 그룹을 무시한다.
# 그룹은 상속되지 않는다. 그래서 이름을 부른 봇에게 `Allow: /`만 적으면
# 아래 Disallow 목록이 통째로 사라져 로그인 게이트 뒤 경로까지 열린다.
# (2026-09-19) 실제로 bingbot·OAI-SearchBot·Claude-SearchBot 등이 그 상태였다.
#
# 해결. 연속된 User-agent 줄은 하나의 그룹을 공유하므로, 허용 봇을 전부
# 한 그룹에 모으고 규칙을 한 번만 적는다. 봇을 추가할 때는 이 목록에 이름을
# 한 줄 더하기만 하면 되고, Disallow를 따로 복사하지 않는다.
#
# Disallow 목록은 site-qa.config.json의 privatePaths와 같아야 한다. 한쪽만
# 고치면 검사가 잡는다.

# ─── 모든 크롤러 + 이름을 밝힌 검색·AI 검색 크롤러 (같은 규칙) ───
