# 알림톡 템플릿 초안 (Solapi 심사 제출용)

> 2026-07-30 작성. 카카오 비즈니스 채널(Law-Caddy) 심사 통과 후 Solapi에 발신프로필 연동 →
> 아래 템플릿을 등록해 심사(통상 2~3영업일)를 받는다.
> 알림톡 규칙: 고정 문구 + `#{변수}`만 허용, 광고성 문구 불가(정보성), 버튼에 링크 가능.
> **케어 메시지는 AI 자유 생성이라 알림톡 불가 — 문자(SMS/LMS) 유지.**

## 1. 수임계약 전자서명 요청 (`lawcaddy_sign_01`)

```
[#{사무소명}] 사건위임계약서 전자서명 안내

#{의뢰인명}님, 안녕하세요.
진행하실 사건의 위임계약서가 준비되어 전자서명을 요청드립니다.

■ 담당: #{변호사명} 변호사
■ 유효기간: 발송 후 24시간

아래 버튼을 눌러 계약서를 확인하고 서명해 주세요.
```
- 버튼: [계약서 확인·서명] → WL(웹링크) `#{서명링크}`
- 변수: 사무소명, 의뢰인명, 변호사명, 서명링크

## 2. 의뢰인 포털 안내 (`lawcaddy_portal_01`)

```
[#{사무소명}] 사건 진행 상황 안내 페이지

#{의뢰인명}님, 안녕하세요.
사건 진행 상황과 다가오는 일정을 언제든 확인하실 수 있는 전용 페이지를 안내드립니다.

■ 담당: #{변호사명} 변호사

궁금하신 점은 언제든 연락 주세요.
```
- 버튼: [진행 상황 확인] → WL `#{포털링크}`
- 변수: 사무소명, 의뢰인명, 변호사명, 포털링크

## 3. 성공보수 청구 안내 (`lawcaddy_fee_01`)

```
[#{사무소명}] 성공보수 정산 안내

#{의뢰인명}님, 안녕하세요.
진행해 드린 사건이 마무리되어 위임계약에 따른 성공보수를 안내드립니다.

■ 청구 금액: #{청구금액}원
■ 담당: #{변호사명} 변호사

입금 계좌 등 자세한 사항은 개별 안내드립니다.
궁금하신 점은 편하게 연락 주세요.
```
- 변수: 사무소명, 의뢰인명, 청구금액, 변호사명

## 4. 기한·기일 안내 (`lawcaddy_deadline_01`)

```
[#{사무소명}] 일정 안내

#{의뢰인명}님, 안녕하세요.
사건 관련 일정을 안내드립니다.

■ 일정: #{일정명}
■ 일시: #{일자}
■ 담당: #{변호사명} 변호사

준비가 필요한 사항은 별도로 안내드립니다.
```
- 변수: 사무소명, 의뢰인명, 일정명, 일자, 변호사명

## 연동 순서 (심사 통과 후)

1. Solapi 콘솔 → 카카오 채널 연동 (검색용 ID + 관리자 휴대폰 인증)
2. 위 4종 템플릿 등록 → 카카오 심사 대기
3. 템플릿 승인 후 코드 전환: `/api/notify/client`에 `type: "ATA"` 경로 추가 —
   템플릿 ID·변수 매핑, **실패 시 기존 문자(SMS)로 자동 대체 발송**(Solapi 대체발송 옵션)
4. 케어 메시지는 문자 유지 (자유 텍스트라 알림톡 불가)
