## 발견

### 1. 에이전트 하나만 실패해도 다음 단계가 영영 열리지 않고, 다시 시도 버튼도 없다 · 심각도 **막힘**
- 어디서: AI 분석 화면
- 무슨 일이: 네 칸 중 셋은 초록 체크, 하나는 빨간 느낌표가 떴다. "생성할 문서 유형" 칸이 아예 나타나지 않아 체크포인트로 못 넘어간다. 실패한 칸을 눌러도 "오류: …" 한 줄뿐, 다시 돌릴 버튼이 없다. 결국 "이전 단계"로 새 상담부터 다시 해야 하고, 성공한 세 에이전트가 쓴 요금은 버려진다.
- 근거: `src/pages/AgentsPage.tsx:223-226` (`allCompleted = completedCount === AGENTS.length`) → `:504` 문서 유형 칸은 `allCompleted`일 때만 렌더 · `:445-448` 오류 분기에 재시도 버튼 없음 · `src/hooks/useAgents.ts:535-540` 실패는 `status: "error"`로 고정되고 재실행 경로 없음
- 고칠 방향: 실패한 에이전트만 다시 돌리는 버튼을 카드에 붙이고, 완료된 결과만으로도 체크포인트 진행을 허용한다.

### 2. 법제처 실존 검증을 해 놓고 결과를 화면에 안 보여준다 — 초록 동그라미는 AI가 스스로 찍은 것 · 심각도 **위험**
- 어디서: AI 분석 화면 → 판례 검색 결과 탭
- 무슨 일이: 사건번호 옆에 "🟢"가 붙어 있어 검증된 판례로 읽힌다. 실제로는 프롬프트가 AI에게 "🟢를 붙여라"고 시킨 것이고, 코드가 법제처에 사건번호를 조회해 얻은 "실존 확인/미확인" 결과는 브라우저 콘솔에만 찍히고 화면·저장 어디에도 반영되지 않는다. 변호사는 허위 사건번호를 걸러낼 단서를 화면에서 얻을 수 없다.
- 근거: `src/hooks/useAgents.ts:561-590` — `caseRefs` 지역 배열에 `ref.source = "law.go.kr-verified" | "unverified"`를 써 넣지만 그 뒤로 어디에도 쓰지 않음(`:592 setAgents(finalStates)`에 포함 안 됨) · `src/services/prompts.ts:459` "사건번호: {사건번호} 🟢", `:436-437` RAG 결과도 "🟢 확인됨"으로 인용하라고 지시 · `src/pages/AgentsPage.tsx:440-442` 결과를 원문 텍스트로만 출력 · 검증 UI 부재는 `src` 전체 grep(`law.go.kr-verified`, `CaseRef`)에서 훅·타입·프롬프트 외 사용처 없음으로 확인
- 고칠 방향: 검증 결과를 에이전트 상태에 담고, 사건번호마다 "법제처 확인됨 / 미확인" 배지를 화면에 그린다. 미확인 사건번호는 문서 생성 프롬프트로 넘기지 않는다.

### 3. 판례에 링크가 없다 — 눌러서 원문으로 갈 수 없다 · 심각도 **위험**
- 어디서: AI 분석 화면 → 판례 검색 결과 탭
- 무슨 일이: 사건번호를 눌러 원문을 확인하려 해도 아무것도 눌리지 않는다. 법제처에서 받아온 판례일련번호(원문 조회 키)를 갖고 있으면서 화면엔 쓰지 않는다. 검증하려면 사건번호를 손으로 옮겨 적어 따로 검색해야 한다.
- 근거: `src/pages/AgentsPage.tsx:440-442` `whitespace-pre-wrap` 텍스트 출력만 존재 · `src/services/precedent-api.ts:22` `serialNumber` 보유, `:128-170` 프롬프트용 텍스트로만 변환, URL 생성 없음 · `src` 전체에 `law.go.kr` 링크 생성 코드 없음(grep)
- 고칠 방향: 결과 텍스트에서 사건번호를 찾아 법제처 판례 상세 페이지로 가는 링크로 바꾸고, 링크 옆에 "원문 보기" 한 줄을 붙인다.

### 4. 체크포인트에서 "이전 단계"를 누르면 분석 전체가 처음부터 다시 돌고 사건 파일이 하나 더 생긴다 · 심각도 **위험**
- 어디서: 체크포인트 화면 → 이전 단계 → AI 분석 화면
- 무슨 일이: 질문을 보다가 판례 결과를 한 번 더 확인하려고 "이전 단계"를 눌렀다. 화면이 다시 0/4부터 시작해 음성 변환·법제처 검색·AI 호출을 전부 반복하고, 끝나면 "사건 파일이 자동 생성되었습니다"가 또 뜬다. 요금은 두 배, 사건 목록엔 같은 의뢰인 사건이 둘, 무료 플랜이면 월 5건 한도도 하나 더 소모된다.
- 근거: `src/pages/CheckpointPage.tsx:422` `navigate(-1)` → 녹음 화면이 넘겼던 원래 state(파일 포함)로 복귀 · `src/pages/AgentsPage.tsx:88` `if (!rawState?.files?.length && restoreFromCache(...))` — 파일이 있으면 캐시 복원을 건너뛰고 `:94-216` 전체 재실행 · `:74` `createdCaseId` 초기값은 `state.caseId`뿐이라 새로 만든 사건 ID를 기억 못 함 → `:254-259` 자동 사건 생성 재발동 · `functions/api/_shared/plan.ts:175-185` 사건 수가 무료 한도 기준
- 고칠 방향: 완료된 분석은 캐시를 우선 복원하고, 새로 만든 사건 ID를 세션에 저장해 재생성을 막는다. 체크포인트의 "이전 단계"는 재실행 없이 결과만 보여주는 화면으로 보낸다.
- (확신: 중간 — 브라우저 뒤로가기 시 history state에 File 객체가 남아 있는지는 브라우저 동작에 따라 다를 수 있다. 남지 않더라도 `:74`의 사건 ID 미보존과 `:85-94` 재실행 구조는 그대로다.)

### 5. 체크포인트 답변이 어디에도 저장되지 않는다 — 문서 화면에서 뒤로 오면 전부 사라진다 · 심각도 **위험**

- 무슨 일이: 질문 4개에 답을 길게 적고 "문서 생성"으로 넘어갔다가, 한 답을 고치려고 "이전 단계"를 누르니 답변 칸이 전부 비어 있다. 첨부한 파일·녹음도 없다. 사건 상세에서 나중에 "그때 뭐라고 답했지" 하고 찾아볼 곳도 없다.

### 6. 녹음이나 파일만으로 답한 질문은 "답변 완료"로 표시되지만 문서엔 반영되지 않는다 · 심각도 **위험**

### 7. 무료 한도가 찼다는 사실을 수 분 기다린 끝에, 그것도 "버그 리포트 하세요"라는 문구로 알게 된다 · 심각도 **위험**
- 어디서: AI 분석 화면 (+ 우상단 알림)
- 무슨 일이: 무료 플랜으로 이번 달 6번째 상담을 넣었다. 새 상담 화면은 아무 말 없이 통과시키고, 분석 화면에서 "법제처 판례 DB를 뒤지고 있습니다…"가 한참 돌더니 네 칸 모두 "오류: Claude API 호출 실패: HTTP 402 무료 플랜의 이번 달 사건 분석 5건을 모두 사용했습니다…"가 뜬다. 동시에 우상단에 "API 오류 발생 … 버그 리포트 버튼으로 관리자에게 알려주세요"가 뜬다. 요금제 문제인데 고장 신고를 하라고 한다.

### 10. 몇 분 걸리는지 아무 데도 없고, 처음 몇 분은 진행률이 0/4에 멈춰 있다 · 심각도 **답답**
