# Law-Caddy 예행연습 종합 (2026-09-11, 2회 루프)

- 사람: 부산 1인 법률사무소 40대 후반 변호사 김 변호사(개발자 아님, 휴대폰 녹음 → 사무실 PC 작업, 사무직원 1명). 2차에서는 사무직원 이 실장과 의뢰인 박 사장 관점을 더함.
- 방법: 1차 8영역 + 2차 6관점(가로지르기·재점검) 점검 14건, 코드 추적(화면→훅→서버 함수→저장 규칙). 공개 화면(첫 화면·로그인·요금제·질문)은 실제 사이트에서 직접 봄. 로그인 뒤 화면은 코드로만 검토.
- 상위 주장 20여 건은 본 세션에서 코드로 재확인함. 나머지는 점검자 보고 그대로이며 고치기 전 코드로 다시 확인해야 함.
- 집계: 총 253건 — 막힘 22 · 위험 82 · 답답 98 · 말 51
- 심각도: 막힘=업무를 못 한다 / 위험=실수로 잃거나 잘못 판단한다 / 답답=되긴 하는데 돌아간다 / 말=문구·용어
