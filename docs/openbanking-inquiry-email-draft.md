- 또는 이메일 문의 폼: https://callcenter.kftc.or.kr/qna/qna_form.jsp?SITE_ID=69 (업무: 오픈뱅킹)

**제목**: 오픈뱅킹 조회업무 이용기관 등록 자격 문의 (법률서비스 SaaS)

안녕하세요,

법률사무소 업무 자동화 소프트웨어(SaaS)를 개발 중인 스타트업입니다.
저희 서비스는 변호사가 본인 명의로 보유한 은행 계좌·카드의 거래내역을 자동으로 수집하여 회계 장부(수임료 입금 매칭, 경비 분류)를 자동화하는 기능을 제공하려고 합니다. 자금이체(송금) 기능은 사용하지 않고, **조회 전용**으로만 이용할 예정입니다.

아래 사항이 궁금하여 문의드립니다.

1. **이용기관 자격 관련**
   저희는 별도로 등록된 "핀테크기업" 인증이나 전자금융업 등록이 되어 있지 않은 일반 소프트웨어 회사입니다. 이런 경우에도 오픈뱅킹 조회업무(거래내역조회, 카드청구상세정보조회 등)의 이용기관으로 신청·등록이 가능한지, 그리고 신청 시 어떤 자격 요건(사업자등록증 종류, 자본금, 재무 요건 등)이 필요한지 알고 싶습니다.

2. **보증보험 가입 의무 관련**
   자금이체(출금이체) 기능은 사용하지 않고 조회 업무만 이용할 예정인데, 이 경우에도 보증보험 가입이 필수인지 확인 부탁드립니다.

3. **이용 절차 및 심사 기간**
   이용신청부터 실제 서비스 개시까지 전체 절차(이용신청 → 심사 → 개발/테스트 → 계약)의 예상 소요 기간을 알고 싶습니다.

4. **카드 거래내역 조회 관련**
   카드청구상세정보조회 API 응답의 `merchant_name_masked` 필드가 실제로는 어느 정도까지 마스킹되어 제공되는지(예: 앞 2글자만 노출 등) 궁금합니다.

바쁘신 중에 답변 주시면 감사하겠습니다.
