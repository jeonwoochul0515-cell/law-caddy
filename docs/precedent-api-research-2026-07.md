# 유료 판례 API 시장 조사 보고서 (2026-07-30)

## 결론
한국에는 구매 가능한 판례 데이터 API/라이선스 상품이 존재하지 않는다.
현 구성(법제처 무료 OpenAPI + 자체 RAG DB 231만 건) 유지가 유일한 선택.

## 업체별
- 엘박스: 약 500만 건(하급심 97%). 외부 판매 ✕ — 자사 SaaS 좌석 판매만. 연구용 lbox-open 15만 건만 공개
- 로앤컴퍼니 빅케이스: 506만 건+. 외부 판매 ✕. 슈퍼로이어 "458만 건" = 자사 빅케이스 DB
- 케이스노트: 약 300만 건. 외부 판매 ✕ (대학도서관용 CaseNote Pro만)
- 인텔리콘 U-LEX 등: B2B 판례 API 상품 확인 안 됨
- 사법정보공유포털: 2026-04 "API 제공 계획 없음" 회신 (기존 확인 사항)

## 격차 분석
- 우리 231만 = 엘박스 2021년 수준. 격차 ~270만 건은 2021년 이후 선고분 + 하급심
- 판결문 공개율: 연간 선고 약 130만 건 중 약 43만 건 공개(약 1/3). 누적 공개 풀 약 550만 건

## 보강 경로 (권고 순)
1. AI허브 판결문 원문 약 25만 건 — 무료, 영리 서비스 활용 가능(출처 명시). RAG 흡수 후보 1순위
2. 판결서 인터넷열람 건당 1,000원 — 온디맨드 구매·축적 (대량 크롤링 부적합)
3. 2023-01 이후 미확정 민사·행정·특허 공개 확대분 모니터링 + 포털 정책 분기별 재확인
