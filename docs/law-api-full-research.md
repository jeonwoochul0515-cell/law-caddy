# 법제처 공공 API 전수 조사 결과

> 4개 에이전트 팀이 법제처 OpenAPI 전체를 테스트하여 Law-Caddy 활용 가능한 API를 선별한 결과.

---

## 1. 활용 가능한 API 전체 목록

### Tier 1: 핵심 (반드시 사용)

| API | target | 엔드포인트 | 데이터 건수 | 핵심 반환 필드 | 활용 에이전트 |
|-----|--------|-----------|------------|---------------|--------------|
| **판례 검색** | `prec` | lawSearch.do | 수만건 | 사건번호, 사건명, 선고일, 법원명 | 한판서 |
| **판례 상세** | `prec` (ID) | lawService.do | - | 판시사항, 판결요지, 참조조문, 참조판례, **판례내용 전문** | 한판서 |
| **지능형 법령검색** | `aiSearch` | lawSearch.do | - | 법령명, 조문번호, **조문내용 전문**, 조문제목 | 서혜안 |
| **연관법령** | `aiRltLs` | lawSearch.do | - | 법령명, 조문번호, 조문제목 (내용 없음) | 서혜안 |
| **헌재결정례** | `detc` | lawSearch.do | 다수 | 사건번호, 판시사항, 결정요지, 참조조문, **전문** | 한판서 |
| **법령해석례** | `expc` | lawSearch.do | - | 안건번호, 질의요지, **회답, 이유 전문** | 윤율무 |
| **법령용어-조문 연계** | `lstrmRltJo` | lawService.do | - | 법령명, 조번호, **조문내용 전문** | 서혜안 |

### Tier 3: 보조 활용

| API | target | 엔드포인트 | 핵심 용도 |
|-----|--------|-----------|----------|

## 2. 핵심 발견 사항

### 2.1 `aiSearch` — 조문 원문까지 반환

```json
{
  "법령명": "민법",
  "조문번호": "0394",
  "조문제목": "손해배상의 방법",
  "조문내용": "제394조(손해배상의 방법)다른 의사표시가 없으면 손해는 금전으로 배상한다."
}
```

기존 `law` target은 법령 메타데이터만 반환하지만, `aiSearch`는 **조문 원문**까지 포함. 서혜안이 쟁점 분석 시 정확한 법조문 텍스트를 참조 가능.

### 2.2 `aiRltLs` — 사건 유형별 정확도 차이

| 검색어 | 정확도 | 반환된 핵심 조문 |
|--------|--------|-----------------|
| "부당해고" | ★★★★★ | 근로기준법 제23조, 제24조, 제27조, 제28조, 제30조 |
| "이혼" | ★★★★☆ | 민법 제834조~제839조, 가사소송법 제22조 |
| "사기" | ★★★☆☆ | 형법 제347조, 제348조 |
| "손해배상" | ★★☆☆☆ | 민법 제394조, 제763조 (제750조 누락) |

→ "부당해고"처럼 구체적 키워드일수록 정확도 높음. "손해배상"처럼 범용적이면 노이즈 증가.

### 2.3 `nlrc` — 노동 사건의 게임체인저

38,392건의 노동위원회 심판례. 판정사항, 판정요지, 판정결과(인용/기각) 포함.  
부당해고 사건에서 대법원 판례 + 노동위원회 심판례를 함께 제시하면 실무 설득력 극대화.

### 2.4 `lstrmRltJo` + `dlytrmRlt` 조합 — 가장 강력한 파이프라인

```
의뢰인: "보증금을 못 받았어요"
    ↓ dlytrmRlt ("보증금" → "임대차보증금", "보증금반환채권")
    ↓ lstrmRltJo ("임대차보증금" → 주택임대차보호법 제3조, 제3조의3 조문 전문)
    ↓ 서혜안이 정확한 법조문으로 쟁점 분석
```

### 2.5 `lstrmRlt` — 의뢰인 메시지에 활용

```
법령용어 "손해배상" → 일상용어:
  동의어: "손배"
  상위어: "배상"
  연관어: "노란봉투", "배상금", "손실보상"
```

의뢰인 카카오톡 메시지 생성 시 법률 용어를 쉬운 말로 바꾸는 데 활용.

## 3. 에이전트별 최적 API 활용 전략

### 한판서 (판례 검색)

```
1. prec (판례 검색) — 키워드로 판례 목록
2. prec (판례 상세) — 상위 5건 전문 조회 (판시사항, 참조조문, 참조판례)
3. detc (헌재결정례) — 관련 헌재 결정
4. 사건 유형별:
   - 노동: nlrc (노동위원회 38,392건)
   - 공정거래: ftc (공정위 2,736건)
   - 인권: nhrck (인권위 622건)
```

### 서혜안 (쟁점 분석)

```
1. aiRltLs (연관법령) — 키워드 → 관련 법령 조문 목록 (10건)
2. aiSearch (지능형 검색) — 키워드 → 조문 원문 포함 (5건)
3. lstrmRltJo (용어-조문 연계) — 법률용어 → 관련 조문 전문
```

### 윤율무 (적법성 검증)

```
1. expc (법령해석례) — 법제처 유권해석 (질의요지/회답/이유)
2. aiSearch (지능형 검색) — 적법성 관련 법조문 원문
```

### 의뢰인 메시지 (보조)

```
1. lstrmRlt (법령→일상용어) — 법률 용어를 쉬운 말로 변환
2. dlytrmRlt (일상→법령용어) — 의뢰인 입력을 법률 용어로 변환
```
